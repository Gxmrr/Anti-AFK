# Anti-AFK

A simple Roblox Anti-AFK script with a minimal draggable UI.

### Features

- Anti-AFK protection
- ON/OFF toggle
- Session timer
- FPS counter
- Draggable interface
- Minimal dark UI

## Usage

Execute the script while in a Roblox game and use the **ON/OFF** button to control Anti-AFK.
